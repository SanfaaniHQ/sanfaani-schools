# Project Overview

## Product

Sanfaani Schools is a scratch-card based online result checker for schools.

## Users

- Super Admin
- School Admin
- Parent/Student
- Teacher later
- Affiliate later

## Core Flow

1. School uploads students.
2. School uploads results.
3. Sanfaani generates scratch cards.
4. Parent enters Student ID, school, session, term, PIN, and serial.
5. System validates access.
6. Result is displayed.
7. Parent prints or downloads result.
